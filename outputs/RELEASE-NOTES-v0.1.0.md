# MoRead 墨读 0.1.0

Windows 上只读的 Markdown 阅读器。打开文件夹，读，然后关掉——它不会改动你任何一个字节。

首个可用版本，包含 M0–M14 全部功能。

## 下载哪个

| 文件 | 大小 | 适合 |
|---|---|---|
| `MoRead_0.1.0_x64-setup.exe` | 2.69 MiB | **推荐**。装完双击 `.md` 直接打开；从"应用和功能"可正常卸载 |
| `MoRead-0.1.0-x64-portable.exe` | 5.05 MiB | 单文件直跑，不写注册表、不抢默认程序。放 U 盘也能用 |

两者功能完全一致，差别只在有没有写文件关联和卸载项。

> 两个附件都用纯 ASCII 文件名。GitHub 上传时会**滤掉 asset name 里的非 ASCII 字符**——
> 本地叫 `MoRead-免安装版.exe`，传上去会变成 `MoRead-.exe`（中文整段消失）。
> 这不只是难看：中文名在各种下载器、`curl -O`、命令行环境里都会变成乱码。
> 中文说明放在这里，文件名留给机器。

**系统要求**：Windows 10 1803+ / Windows 11，x64。WebView2 运行时是系统自带的（1803 之后默认预装），不需要另装 .NET 或 Node。

## 这一版有什么

- **只读**：不写文件、不弹"未保存"、没有撤销栈。你的文档一个字节都不会变
- **真实工作区**：文件树多级展开；外部改动自动重载，并停在原来读的位置
- **大纲**：按 H1–H3 生成，滚动时高亮当前章节；启动默认停在这里
- **跨文件搜索**：右侧栏三档范围（当前标签 / 所有标签 / 整个工作区）；命中定位到"第几次出现"，长文档也精确落点
- **历史**：按打开时间倒序，最多 24 条；文件不在了整行置灰、点不动
- **长文档虚拟滚动**：2.5 MB 文档实测 **60.2 fps**，全量渲染对照组 7.4 fps
- **标签页**：拖拽换位、固定、右键批量关闭、双击关闭；装不下时收缩 → 撤图标 → 横向滚动 → `⌄` 菜单
- **六套主题**：暖纸 / 竹青 / 天青 × 浅深，全部通过 WCAG 对比度审计
- **正文字号**：12–22 px，`Ctrl+滚轮` 直接调；只放大正文，界面像素不动
- **侧栏可拖可折叠**：200–480 px，双击复位；折叠后留 44 px 图标栏
- **托盘常驻**：点右上角关闭是进托盘，不是退出
- **安装包安静**：装完自动进结束页；装卸时若程序在跑，静默关掉，不弹"点击确定以终止运行"

| `Ctrl+滚轮` | 连续调字号 |

## 已知限制

- 只读，不提供编辑。这是设计目标，不是待补的功能
- 不渲染 Mermaid 图（代码块正常高亮）
- 固定标签在横向滚动时不粘在左边——Chrome 会粘住，这里没做
- 单文件上限约 8 MB；更大的文件标记解析会成为瓶颈
- 仅 Windows。Tauri 理论上能跨平台，但托盘、文件关联、安装包这些都只做了 Windows 的实现
