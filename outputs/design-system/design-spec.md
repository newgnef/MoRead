# MoRead 设计规范 v1.2

> Windows 只读 Markdown 阅读器 · 配套 `tokens.css` / `tokens.ts` / 原型 6 屏
>
> **v1.2（2026-10-18）**：新增 §2.4 正文字号可调（12–22px，只缩放阅读域，界面不缩放）。
>
> **v1.1（2026-10-18）**：新增 §1.4 主题族 —— 竹青 / 墨绿、天青 / 深蓝，共六套；主题从单轴（浅深）升级为两轴（浅深 × 色调）。
>
> **核心立场**：阅读器的装饰每多一分，读者的注意力就少一分。本系统没有阴影、没有渐变、没有大圆角、没有高饱和色——全靠 1px 细线、六级灰阶和一个墨绿强调色撑起层级。

---

## 1 色彩

每个令牌给出 `浅色值 / 深色值`。深色不是浅色反相，而是重新调过的一套暖墨色：底色偏暖、强调色提亮，保证正文对比度仍在 9:1 以上。默认这一族叫**暖纸 / 暖墨**；另有两族同构的色调（竹青 / 墨绿、天青 / 深蓝）见 §1.4。

### 1.1 表面与描边

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--mr-chrome` | `#F4F0E8` | `#141413` | 窗口底、侧栏底 |
| `--mr-canvas` | `#FBFAF7` | `#1C1B19` | 阅读画布（比纯白低 3% 亮度，长读不刺眼） |
| `--mr-surface` | `#FFFFFF` | `#2A2825` | 激活标签、卡片、列表面板 |
| `--mr-surface-code` | `#F5F2EA` | `#232220` | 代码块、行内码底 |
| `--mr-surface-tint` | `#F1EDE4` | `#232220` | 表头、引用块底 |
| `--mr-surface-track` | `#E9E4D9` | `#201F1C` | 分段控件轨道、行悬停底 |
| `--mr-border` | `#E5DFD0` | `#302E29` | 主分隔线（替代阴影承担全部层级） |
| `--mr-border-soft` | `#EFECE6` | `#262521` | 组内分隔（设置项、表格行） |
| `--mr-border-strong` | `#D4CCB5` | `#3A3833` | 可交互控件描边 |

### 1.2 文字阶梯（六级）

**正文只能用 1–3 级**；4–6 级仅限图标、注释、装饰性元信息。

| 令牌 | 浅色 | 深色 | 对比度（浅/深） | 用途 |
|---|---|---|---|---|
| `--mr-text-1` | `#1F1E1B` | `#EDE9E1` | 16.0:1 / 14.2:1 | 文档标题、主标签、当前项 |
| `--mr-text-2` | `#3A3833` | `#C9C4BB` | 11.3:1 / 9.9:1 | 正文（屏幕上出现最多） |
| `--mr-text-3` | `#5C5A55` | `#A9A49A` | 6.6:1 / 6.9:1 | 次级标签、引用文、搜索片段 |
| `--mr-text-4` | `#8A8578` | `#8A8578` | 3.5:1 / 4.7:1 | 图标描边、代码注释、未激活标签 |
| `--mr-text-5` | `#938D80` | `#7A756C` | 3.2:1 / 3.8:1 | 字段描述、路径、说明性元信息 |
| `--mr-text-6` | `#A39D8F` | `#6E6963` | 2.6:1 / 2.9:1 | 时间戳、禁用态、装饰性小图标 |

### 1.3 强调色

没用常规蓝色链接色，选了**松墨绿**——贴合「墨读」的纸质调性，暖纸底上 6.1:1、深色底上 7.5:1，均达 AA。每屏只允许出现一个强调色。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--mr-accent` | `#2F6B4F` | `#7FB894` | 主按钮底、链接、选中项、进度条 |
| `--mr-accent-strong` | `#245B41` | `#9CCBAB` | 按钮悬停、代码变量名 |
| `--mr-accent-soft` | `#E3E9DE` | `#26332A` | 选中行底、焦点环外圈、内联高亮 |
| `--mr-accent-armor` | `#DCE4D8` | `#2E3A32` | 引用块描边（带绿调） |
| `--mr-bronze` | `#B89968` | `#C8A876` | 文件夹图标、警告点缀（唯一第二色） |
| `--mr-warn-bg` / `--mr-warn` | `#FBF0DC` / `#B89968` | `#2E2519` / `#C8A876` | 警告徽章底与前景 |

### 1.4 主题族（3 色调 × 浅深 = 6 套）

上表是**暖纸 / 暖墨**这一族的色值，也是默认主题。除此之外还有两族，只在
`data-palette` 变化时覆盖「表面 / 描边 / 文字 / 强调软色」，字体、字号、圆角、
间距、阴影一律不动。

| 色调 | `data-palette` | 窗口底（浅/深） | 画布（浅/深） | 强调（浅/深） |
|---|---|---|---|---|
| 暖纸 / 暖墨 | `paper`（默认，不写属性） | `#F4F0E8` / `#141413` | `#FBFAF7` / `#1C1B19` | `#2F6B4F` / `#7FB894` |
| 竹青 / 墨绿 | `moss` | `#EDF2E8` / `#0E1310` | `#F7FAF3` / `#141A15` | `#2F6B4F` / `#7FB894` |
| 天青 / 深蓝 | `blue` | `#ECF1F7` / `#0D1218` | `#F7FAFD` / `#121821` | `#2F6796` / `#7FB3E0` |

规则：

1. **浅深与色调正交**。`data-theme` 只管明暗，`data-palette` 只管色相；六个组合都能选
2. **深色块权重更高**：`[data-palette="x"][data-theme="dark"]` 是两个属性选择器，
   稳压 `[data-theme="dark"]`，所以不必把深色值再抄一遍
3. **只有一处需要多写**：每增加一族要写两个块（浅 + 深），且必须一起写 ——
   漏了深色块会出现"深色模式下仍是浅色纸底"这种最刺眼的 bug
4. **色卡就是真主题**：外观面板里的预览不是画出来的色块，而是给元素挂上
   `data-palette` / `data-theme` 让令牌自己算，因此永远不会有"色卡过期"的问题

## 2 字体

### 2.1 字体族

| 令牌 | 字体 | 职责 |
|---|---|---|
| `--mr-font-sans` | Noto Sans SC | 正文与全部 UI。中文全字重可用、小字号不糊，拉丁字母与原 Inter 同源 |
| `--mr-font-serif` | Source Han Serif CN | 文档标题、引用块、产品字标。给阅读器一点「书」的质感 |
| `--mr-font-mono` | JetBrains Mono | 代码块、行内码、路径、数值 |
| `--mr-font-latin` | Inter | 纯拉丁元信息与数字，配合 `tabular-nums` 对齐时间戳与计数 |

### 2.2 字号阶梯（14 级，以用途命名）

| 令牌 | 字号 / 行高 | 字重 · 字族 | 用途 |
|---|---|---|---|
| `display` | 38 / 46 | 700 serif | 文档 H1 |
| `h1` | 30 / 38 | 700 serif | 空态字标 |
| `h2` | 23 / 30 | 600 serif | 文档 H2 |
| `h3` | 18 / 26 | 500 sans | 文档 H3 |
| `section` | 15 / 22 | 500 sans | 分区标题 |
| `lead` | 15.5 / 27 | 400 serif | 引用块 |
| `body` | 15 / 26 | 400 sans | 正文 |
| `body-sm` | 13.5 / 24 | 400 sans | 说明段落（空态、引导页） |
| `ui` | 13 / 20 | 500 sans | 设置项标签、按钮文案 |
| `ui-sm` | 12.5 / 18 | 500 sans | 标签页标题、文件树项 |
| `meta` | 12 / 18 | 400 sans | 提示语、按钮内次级说明 |
| `meta-sm` | 11.5 / 17 | 400 sans | 字段描述、搜索命中片段 |
| `meta-xs` | 11 / 16 | 400 sans | 命中计数、语言标签 |
| `code` | 12.5 / 20 | 400 mono | 代码 |

### 2.3 排版铁律

1. **阅读列宽 ≤ 680px** —— 超过眼睛要来回扫行。默认 680，用户可调 600–1400
2. **中文行高 ≥ 1.7** —— 汉字是方块字，1.5 会挤。正文 26/15 ≈ 1.73
3. **标题 serif，正文 sans** —— 不混用
4. **正文左对齐** —— 除空态与引导页说明外，永不居中、永不两端对齐

### 2.4 正文字号可调（12–22px）

只有**一个**旋钮：正文字号，默认 15px。其余 13 级不单独调，按同一倍率联动。

| 项 | 规定 |
|---|---|
| 范围 / 步进 | 12–22px，1px 一档；默认 15 |
| 载体 | `--mr-read-scale`（1 = 15px）写在 `<html>` 上 |
| 生效范围 | 仅 `.mr-article` 子树 —— 它在自己身上重算 11 组字号 / 行高令牌 |
| 界面 | 读 `:root` 原值，**任何档位都不跟着放大**（标签页、侧栏、面板像素级不变） |
| 版心 | `--mr-reading-w` 固定，不随字号缩放 —— 放大的是字，不是纸 |
| 入口 | 外观面板 `− 15px +`、`Ctrl+滚轮`、`Ctrl+=` / `Ctrl+-` / `Ctrl+0` |

> 铁律 2 在任意档位都成立：行高与字号同倍率，比值恒为 1.73。
> 不做整页 `zoom` —— 那会连工具栏一起放大，读起来像浏览器按错了键。

## 3 间距 / 圆角 / 阴影

### 3.1 间距阶梯（4px 基准）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--mr-sp-1` | 4px | 图标与文字、紧凑间隙 |
| `--mr-sp-2` | 8px | 代码块行距、按钮图标间距 |
| `--mr-sp-3` | 12px | 列表行内边距、卡片内间距 |
| `--mr-sp-4` | 16px | 段落间距、面板内边距 |
| `--mr-sp-5` | 20px | 设置行内边距、按钮内边距 |
| `--mr-sp-6` | 24px | 区块间距 |
| `--mr-sp-8` | 32px | 阅读区上下留白 |
| `--mr-sp-10` | 40px | 大区块分隔 |
| `--mr-sp-16` | 64px | 空态页顶部留白 |

> ⚠️ 原型稿里出现过 3 / 5 / 7 / 9 / 11 这类奇数间距，那是绘制时的临时值，**不要照抄进代码**，落地一律吸附到上表 9 档。

### 3.2 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `--mr-radius-xs` | 3px | 进度条 |
| `--mr-radius-sm` | 4px | 树项、表格、分段选项 |
| `--mr-radius-md` | 6px | 按钮、输入框、标签、代码块 |
| `--mr-radius-lg` | 8px | 卡片、列表面板、设置面板 |
| `--mr-radius-pill` | 11px | 开关 |

最大只到 8px。超过 12px 就会从「工具」滑向「消费级 App」。

### 3.3 阴影

**全站只有一处**：`--mr-shadow-popover: 0 4px 16px rgba(31,30,27,.10)`，仅用于浮层（下拉、气泡、右键菜单）。其余层级关系一律用 1px 细线承担。

## 5 组件规范

### 5.1 按钮

| 变体 | 样式 | 使用场合 |
|---|---|---|
| Primary | 底 `--mr-accent`，文字 #FFF，高 38，圆角 6，内边距 0 18 | 一个界面只能有一个 |
| Secondary | 无底，1px `--mr-border-strong`，文字 `--mr-text-2` | 次要动作，与 Primary 并排 |
| Text | 无底无框，文字 `--mr-accent`，内边距 0 4 | 低权重动作（清除记录） |
| Disabled | Primary + `opacity: .4` + `cursor: not-allowed` | 不可用但仍需可见 |

悬停：Primary → `--mr-accent-strong`；Secondary → 底 `--mr-surface-track`。过渡 120ms。

### 5.2 窗口标签

激活态才有 `--mr-surface` 底与 6px 圆角；未激活无底、文字 `--mr-text-4`。中键点击关闭，溢出时横向滚动而非压缩宽度。

### 5.3 侧栏分段 Tab 与文件树

| 状态 | 样式 |
|---|---|
| 默认 | 文字 `--mr-text-2`，左内边距 14，子级 7 |
| 悬停 | 底 `--mr-surface-track`，圆角 4 |
| 选中 | 底 `--mr-accent-soft`，文字与图标转 `--mr-accent`，字重 500 |
| 失效 | 文字 `--mr-text-6` + 删除线（文件被移走） |

### 5.4 表单控件

- 开关：38×21，圆角 11，开态 `--mr-accent`，旋钮 15px 白色
- 分段控件：轨道 `--mr-surface-track` + 内边距 3，激活项 `--mr-surface` 底
- 步进器：高 30，边框 `--mr-border-strong`，左右 28×28 点击区
- 搜索框：高 32，边框 `--mr-border-strong`，聚焦时边框转 `--mr-accent` + 2px `--mr-accent-soft` 外圈

> 设置项**一律即时生效 + 自动保存**，没有「确定 / 取消」按钮。

### 5.5 搜索命中行

必须同时给出**文件名 + 匹配片段**——只给文件名等于让用户再点进去找一次。选中行底 `--mr-accent-soft`。

### 5.6 Markdown 渲染件

| 元素 | 规则 |
|---|---|
| h1 / h2 | Source Han Serif，700 / 600，`--mr-text-1` |
| h3 | 切为 Noto Sans SC 500——三级起用无衬线，避免整页宋体发闷 |
| 代码块 | 底 `--mr-surface-code` + 1px 边框 + 6px 圆角；头部独立一行放语言名与复制按钮 |
| 表格 | 表头底 `--mr-surface-tint`，行间 1px `--mr-border-soft`，无竖线 |
| 引用块 | 底 `--mr-surface-tint`，边框 `--mr-accent-armor`，字体切 serif 并加大行高 |
| 图片 | 最大宽度 100%，圆角 6，缺失时显示占位框 + 原始路径 |

### 5.7 三态规范

| 态 | 要求 |
|---|---|
| 加载 | 骨架屏用 `--mr-surface-track`，不用转圈 |
| 空 | 说清「为什么空」并给一个动作 |
| 错误 | 写清发生了什么 + 下一步怎么办（例：文件缺失 → 显示原路径 + 「移除标签」） |

> **硬要求**：任何数据面都必须实现加载 / 空 / 错误 / 成功四态。禁止静默失败。

## 6 无障碍

| 项 | 要求 |
|---|---|
| 正文对比度 | ≥ 4.5:1。六级灰阶中 1–3 级达标（最低 6.6:1），**4–6 级禁止用于正文** |
| 焦点环 | 2px `--mr-accent` + 2px 偏移，任何情况下不得移除 outline |
| 全键盘 | 每个功能都要有快捷键，不得占用系统级组合键 |
| 缩放 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` + `Ctrl+滚轮`；只缩放**阅读域字号** 12–22px（相对 15 为 80%–147%），界面不缩放，版心宽度与布局不变 |
| 动效 | 尊重 `prefers-reduced-motion`，命中时全部过渡置 0 |
| 触控目标 | 可点击区域最小 28×28，窗口控件 44×39 |

## 7 禁止项

写进 code review checklist 的硬性禁止项：

1. ✕ 大面积阴影与渐变（浮层除外）
2. ✕ 圆角 > 8px
3. ✕ 饱和度 > 40% 的色
4. ✕ 第二个强调色（青铜色仅限文件夹图标与警告点缀）
5. ✕ emoji 当图标（一律 SVG 描边图标）
6. ✕ 正文列宽 > 680px
7. ✕ 正文居中 / 两端对齐
8. ✕ 主题切换加过渡（会闪白，`--mr-dur-theme: 0ms` 硬切）
9. ✕ 设置项加「确定」按钮
10. ✕ 装饰性分隔线（线必须有功能含义）
