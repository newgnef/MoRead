## 1. 产品定位与边界

### 1.1 一句话定位

把一个 `.md` 文件或一整个本地笔记文件夹，**用接近出版物的质量渲染出来**，并提供多标签、大纲、搜索、主题这类"读得下去"必需的阅读能力。

### 1.2 目标场景

| 编号 | 场景 | 频率 | 对应需求块 |
|---|---|---|---|
| S1 | 双击 `.md` 文件直接打开阅读 | 高 | F1 |
| S2 | 打开一个笔记/文档文件夹，左侧树形浏览 | 高 | F1 + F3 |
| S3 | 读长技术文档，靠大纲跳转、靠阅读位置记忆续读 | 高 | F3 |
| S4 | 读含代码块 / 表格 / 公式 / 流程图的文档 | 高 | F2 |
| S5 | 跨文件夹检索某段内容在哪篇文档里 | 中 | F3.7 |

### 1.3 做什么

- `.md` 文件与文件夹的读取、高质量渲染
- 多标签、大纲导航、文档内 / 工作区搜索
- 亮暗主题、阅读位置记忆、大文档流畅滚动
- Windows 系统集成：文件关联、拖拽打开、单实例

### 1.4 明确不做（V1 非目标）

| 非目标 | 理由 |
|---|---|
| **任何编辑与保存**（含自动格式化、front-matter 修正） | V1 铁律：**对源文件只读，零写入**。降低风险，也砍掉 undo/redo、光标模型等 70% 复杂度 |
| 云端同步 / 账号体系 | 纯本地工具 |
| 插件系统 / 主题市场 | 留 P2，V1 只支持自定义 CSS |
| 协同、Git 集成、导出 HTML | 与"阅读器"定位无关 |
| 移动端 / macOS / Linux | V1 只做 Windows，但技术选型不排除后续扩展 |

## 3. 非功能需求

### 3.1 性能指标（硬指标，需实测）

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 冷启动到可交互 | ≤ 1.5 s | 干净系统，首次启动 |
| 1 MB 文档首屏渲染 | ≤ 300 ms | 从点击到首屏可见 |
| 10 万行 / 5 MB 文档 | 可打开，滚动 ≥ 50 fps | 虚拟滚动生效，不出现整页白屏 |
| 文档内搜索响应（5 MB 文档） | ≤ 200 ms | 输入即搜 |
| 工作区文件名搜索（1 万文件） | ≤ 500 ms | 流式扫描 |
| 工作区全文搜索（1 万文件） | ≤ 3 s | 流式扫描 + 结果流式返回 |
| 空载内存占用 | ≤ 150 MB | WebView2 基线约 80–120 MB |
| 安装包体积 | ≤ 15 MB | NSIS 安装包，不含 WebView2 运行时 |
| 二进制实现 | Rust `--release` + LTO | — |

> 说明：网络搜索、云端能力一律不涉及，无网络性能项。

### 3.2 兼容性

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809 (17763) 及以上 / Windows 11 |
| 运行时 | WebView2 Runtime。启动时检测：缺失则弹窗引导下载 Evergreen Bootstrapper；安装包内**不内嵌**固定版运行时（体积换体验） |
| 架构 | x64；ARM64 后续评估 |
| 文件系统 | 支持长路径（>260 字符）、UNC 路径、网络盘（只读） |

### 3.3 安全与隐私

| 项 | 要求 |
|---|---|
| 文件访问范围 | **最小权限**：仅可读取用户显式打开的文件与目录；Tauri capabilities 中 `fs` scope 动态收窄 |
| 网络 | 应用自身零网络请求；仅用户点击外链时调起系统浏览器 |
| 渲染沙箱 | 严格 CSP；禁用 `unsafe-eval`；HTML sanitize 前置 |
| 写盘 | **V1 只写自己的配置目录，永不写入用户文档目录** |
| 遥测 | 无 |

### 3.4 可用性与无障碍

- 全键盘可操作：所有功能有快捷键，焦点环可见
- 快捷键冲突零容忍：不得占用系统级组合键
- 缩放：`Ctrl+=` / `Ctrl+-` / `Ctrl+0` 整体缩放 80%–200%
- 中文排版：正文默认字体栈 `system-ui, "Segoe UI", "Microsoft YaHei"`；中英文混排自动间距

## 5. 技术架构

### 5.1 分层

```
┌── Tauri 主进程（Rust）─────────────────────────────┐
│ 文件 IO · 目录遍历 · 文件监听 · 全文扫描 · 窗口/单实例 │
│ 设置与会话持久化 · WebView2 运行时检测               │
└──────────────────┬───────────────────────────────┘
                   │ Tauri IPC（命令 + 事件）
┌──────────────────▼───────────────────────────────┐
│ 渲染层（WebView2 / TypeScript）                    │
│ 解析(markdown-it) → Sanitize(DOMPurify) → 注入     │
│ → 后处理装饰(Shiki / KaTeX / Mermaid，懒加载)      │
│ 虚拟滚动 · 大纲提取 · 搜索高亮 · 主题变量           │
└──────────────────────────────────────────────────┘
```

### 5.2 技术选型确认表

| 层 | 选型 | 备注 |
|---|---|---|
| 外壳 | Tauri 2.x | Windows 用 WebView2 |
| 前端构建 | Vite + TypeScript | 框架建议 **Svelte 5** 或 React；待确认（§8-Q6） |
| Markdown 解析 | **markdown-it** + 插件 | 比 remark 链路更轻、更快；插件：task-lists / footnote / deflist |
| 输出净化 | DOMPurify | 渲染前后置 |
| 代码高亮 | **Shiki**（`bundle/web` 按需） | 主题与阅读主题联动；语言包懒加载 |
| 数学 | KaTeX | 字体资源本地打包，不走 CDN |
| 图表 | Mermaid（懒加载，独立 chunk） | 约 1 MB+，首屏不加载 |
| 样式基座 | 自研 CSS 变量主题 | 参考 `github-markdown-css` 结构，不直接引入 |
| 虚拟滚动 | 块级虚拟化（自研或 `@tanstack/virtual`） | 按顶层块切分，`IntersectionObserver` 驱动 |
| 文件监听 | Rust `notify` | 带去抖（300ms） |
| 全文搜索 | Rust `ignore` + `regex` **流式扫描**，不建索引 | **决策**：1 万文件量级建索引收益为负，省掉索引维护与失效问题 |
| 中文分词 | `jieba-rs`（仅在需要词级匹配时启用） | V1 先用子串匹配，够用 |
| 持久化 | `tauri-plugin-store`（JSON KV） | 设置 / 最近 / 阅读位置 / 会话 |
| 打包 | NSIS + WebView2 Bootstrapper | 文件关联注册在安装器中 |
| 日志 | `tauri-plugin-log` | 落 `%APPDATA%\MoRead\logs`，滚动 5 MB×3 |

### 5.3 IPC 命令清单（Rust 侧接口，前后端契约）

| 命令 | 入参 | 出参 | 用途 |
|---|---|---|---|
| `read_text_file` | `path: string` | `{ content, mtime, size }` | 读单个 md |
| `open_path_dialog` | `kind: "file"｜"folder"` | `path?` | 系统选择框 |
| `list_dir` | `root, maxDepth` | `TreeNode[]` | 目录树 |
| `watch_path` / `unwatch_path` | `path` | — | 文件监听开关 |
| `scan_text_search` | `root, query, opts` | `Hit[]`（流式事件） | 工作区搜索 |
| `search_index_names` | `root, query` | `Hit[]` | 文件名搜索 |
| `open_external` | `url` | — | 外链（白名单 http/https） |
| `store_get` / `store_set` | `key, value` | `unknown` | KV 持久化 |
| `window_ready_check` | — | `{ webview2: boolean, version }` | 运行时体检 |
| 事件 `fs://changed` | — | `path, mtime` | 文件变化推送 |

### 5.4 渲染管线（性能关键路径）

1. 主线程收到 `content` → 丢给 **Web Worker** 做 `markdown-it` 解析 + 大纲提取
2. 回主线程 → DOMPurify 净化 → 分块插入虚拟列表
3. 可见块内异步装饰：Shiki（worker 内高亮）→ KaTeX（同步）→ Mermaid（懒加载渲染）
4. 装饰完成后**按块标记 ready**，避免整页重排造成滚动抖动

> 关键约束：**任何单次同步任务不得超过 16 ms**；解析、高亮、目录遍历全部异步化。

### 5.5 安全配置要点

- `tauri.conf.json` 的 CSP 收紧到 `default-src 'self'`；`img-src 'self' asset: data:`
- Tauri 2 capabilities 按窗口最小化授权，`fs` 权限用动态 scope
- 图片走 Tauri `asset:` 协议读取，不放开任意路径
