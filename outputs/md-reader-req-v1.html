Windows Markdown 阅读器 · 需求方案

基于 Tauri 2 + WebView2 的纯只读 Markdown 阅读器。
V1 只解决一件事：把本地 Markdown 读到"愿意每天都用"的程度。

1产品定位与边界

一句话定位

把一个 .md 文件或一整个本地笔记文件夹，用接近出版物的质量渲染出来，并提供多标签、大纲、搜索、主题这类「读得下去」必需的阅读能力。

目标场景

编号场景频率对应需求块
S1双击 .md 文件直接打开阅读高F1
S2打开笔记 / 文档文件夹，左侧树形浏览高F1 + F3
S3读长技术文档：靠大纲跳转、靠阅读位置记忆续读高F3
S4读含代码块 / 表格 / 公式 / 流程图的文档高F2
S5跨文件夹检索某段内容在哪篇文档里中F3.7 / F3.9

做什么 / 不做什么

✅ 做什么

  • 文件与文件夹的读取、高质量渲染
  • 多标签、大纲导航、文档内与工作区搜索
  • 亮暗主题、阅读位置记忆、大文档流畅滚动
  • 系统集成：文件关联、拖拽打开、单实例

⛔ 明确不做（V1 非目标）

  • 任何编辑与保存（含自动格式化、front-matter 修正）
  • 云端同步 / 账号 / 协同 / Git 集成
  • 插件系统、主题市场（V1 仅支持自定义 CSS）
  • 导出 HTML、移动端与 macOS / Linux
V1 铁律：对源文件只读，零写入。这条约束同时砍掉了 undo/redo、光标模型、脏数据校验等约 70% 的复杂度——这是选择"先做阅读器"最大的收益。

3.2 兼容性

项要求
操作系统Windows 10 1809 (17763) 及以上 / Windows 11
运行时WebView2 Runtime。启动时检测，缺失则弹窗引导下载 Evergreen Bootstrapper；安装包不内嵌固定版运行时（体积换体验）

3.3 安全与隐私

项要求
文件访问范围最小权限：仅可读用户显式打开的文件与目录；Tauri capabilities 中 fs scope 动态收窄
网络应用自身零网络请求；仅用户点击外链时调起系统浏览器
渲染沙箱严格 CSP；禁用 unsafe-eval；HTML sanitize 前置
写盘只写自己的配置目录，永不写入用户文档目录
遥测无

3.4 可用性与无障碍

  • 全键盘可操作：所有功能有快捷键，焦点环可见
  • 缩放：Ctrl+= / Ctrl+- / Ctrl+0 整体缩放 80 %–200 %
  • 中文排版：正文默认字体栈 system-ui, "Segoe UI", "Microsoft YaHei"；中英文混排自动间距

5.4 渲染管线（性能关键路径）

  1. 主线程收到 content → 交给 Web Worker 做 markdown-it 解析 + 大纲提取
  2. 回主线程 → DOMPurify 净化 → 分块插入虚拟列表
  3. 可见块内异步装饰：Shiki（worker 内高亮）→ KaTeX（同步）→ Mermaid（懒加载渲染）
  4. 装饰完成后按块标记 ready，避免整页重排造成滚动抖动
关键约束：任何单次同步任务不得超过 16 ms；解析、高亮、目录遍历全部异步化。

5.5 安全配置要点

  • tauri.conf.json CSP 收紧到 default-src 'self'，img-src 'self' asset: data:
  • Tauri 2 capabilities 按窗口最小化授权，fs 权限使用动态 scope
  • 图片走 Tauri asset: 协议读取，不放开任意路径
